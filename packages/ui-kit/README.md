# @vpple/ui-kit

> 1:1 clean-room clone of Apple macOS Tahoe and iOS 26 real volumetric liquid glass design systems.

Part of the **[Vpple Open Source Initiative](https://github.com/jabirking-ux/Vpple)**.

## Installation

```bash
npm install @vpple/ui-kit @vpple/sp-pro-display
```

Or via CDN:

```html
<!-- SP Pro Display Typeface -->
<link rel="stylesheet" href="https://jabirking-ux.github.io/Vpple/css/sp-pro-display.css">

<!-- Vpple UI Kit Styles -->
<link rel="stylesheet" href="https://jabirking-ux.github.io/Vpple/css/vpple-ui.css">

<!-- Interactive Controller -->
<script src="https://jabirking-ux.github.io/Vpple/js/vpple-ui.js" defer></script>
```

## Features

- **macOS Window Chrome**: Realistic traffic lights with hover micro-glyphs (`close`, `minimize`, `maximize`), unified toolbars, and split-view sidebars.
- **macOS Menubar**: Apple logo (``), application menus with working dropdowns, live clock, Wi-Fi, battery status, and Control Center flyout.
- **macOS Dock**: Parabolic magnification curve physics, active app running indicators, tooltips, and app launch bounce animations.
- **Control Center**: Wi-Fi, Bluetooth, AirDrop, Focus, Brightness and Sound sliders.
- **Spotlight Search**: Triggerable via `⌘+Space` / `Ctrl+Space` with instant search filtering.
- **HIG Form Elements**: 51x31px Apple switches, continuous fluid sliders, segmented capsule controls, steppers, and glass search bars.
- **Liquid Glass Materials**: Ultrathin, thin, regular, and thick materials with specular edge caustics.
- **SP Pro Display**: Seamlessly integrated with 1:1 metric-identical Apple system typography.
