# @vpple/sp-pro-display

100% metric-identical, clean-room reverse-engineered open-source clone of Apple SF Pro Display. Part of the [Vpple](https://github.com/jabirking-ux/Vpple) project.

## Installation

```bash
npm install @vpple/sp-pro-display
```

Or via direct CSS import:

```css
@import "@vpple/sp-pro-display/css/sp-pro-display.css";
@import "@vpple/sp-pro-display/css/apple-typography.css";
```

## Features

- **18 Styles**: Full matrix across 9 weights (Ultralight to Black) and 9 matching italics.
- **Zero Line-Wrap Delta**: Exact 1:1 metric parity with Apple SF Pro Display.
- **macOS Curve Polish**: Footless digit `1`, round punctuation, and scaled GPOS pair kerning.
- **License**: SIL Open Font License 1.1 (OFL-1.1).
